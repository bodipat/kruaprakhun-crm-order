# Krua Prakhun CRM & Food Ordering System (Lean MVP)

ระบบเว็บไซต์สั่งอาหารและติดตามแคมเปญการตลาด (Direct Sale + CRM Tracking) สำหรับร้าน **"ครัวพระคุณ"** ออกแบบและพัฒนาเป็นเว็บแอปพลิเคชันหน้าเดียว (Single Page Application - SPA) แบบไร้เซิร์ฟเวอร์ โดยใช้ฐานข้อมูลจำลองบนเบราว์เซอร์ (`localStorage`) ทำให้ทดสอบและใช้งานได้ทันทีโดยไม่มีภาระการเชื่อมต่อ Database ภายนอก

---

## 🚀 วิธีการติดตั้งและรันใช้งานภายในเครื่อง (Local Deployment)

ระบบนี้รันด้วยเทคโนโลยีเว็บมาตรฐาน (HTML5, CSS3, ES6 JavaScript) จึงไม่ต้องทำการลง `npm` หรือทำ Build ขั้นสูง คุณสามารถรันเว็บเซิร์ฟเวอร์ด้วย **Python** (ซึ่งมีติดเครื่อง macOS อยู่แล้ว) ได้ทันที:

1. เปิด Terminal ในโฟลเดอร์โครงการนี้:
   ```bash
   cd /Users/peter/.gemini/antigravity/scratch/kruaprakhun-crm-order
   ```

2. เริ่มต้นรัน Local Web Server ด้วย Python 3:
   ```bash
   python3 -m http.server 8000
   ```

3. เปิดเว็บเบราว์เซอร์แล้วเข้าไปที่:
   **[http://localhost:8000](http://localhost:8000)**

## 🛠️ แนะนำโครงสร้าง Workspace Simulator Bar

ที่บริเวณด้านบนของหน้าเว็บจะมี **Simulator Bar** พิเศษสำหรับจำลองสภาพแวดล้อมจริง:
* **Address Bar (แถบ URL จำลอง)**: แสดงค่า URL ของเบราว์เซอร์พร้อม Parameter เพื่อใช้ทดสอบการ Tracking (เช่น `?source=src_pst_a&campaign=camp_01`) สามารถแก้ไขและกด **Enter** เพื่อจำลองพฤติกรรมลูกค้ากดจากที่มาต่างๆ ได้
* **ปุ่มสลับบทบาท (Role Switcher)**: ช่วยให้จำลองขั้นตอนการสั่งซื้อแบบครบวงจร (End-to-End) ได้ในเครื่องเดียว:
  1. **หน้าลูกค้า (Customer)**: ค้นหาเมนูอาหาร ปรับแต่งรสชาติและ Topping สั่งซื้อ ชำระเงิน และติดตามสถานะแบบเรียลไทม์
  2. **ห้องครัว (Kitchen)**: มอนิเตอร์รายการสั่งทำอาหารแยกตามสถานะการทำงาน พร้อมฟังก์ชันเสียงเตือนคำสั่งซื้อเข้าใหม่
  3. **Store Admin**: ดูภาพรวมสถิติตัวเลขวิเคราะห์ยอดขาย ยืนยันสลิปเงินโอน จัดการรายการอาหาร และข้อมูล CRM ลูกค้า
  4. **Marketing Admin**: วิเคราะห์ประสิทธิภาพของแต่ละช่องทางที่มา (Source ROI) และสร้างลิงก์พ่วง QR Code

## 📖 ขั้นตอนแนะนำสำหรับการทดสอบการทำงานของระบบ (Test Walkthrough)

เพื่อให้เห็นภาพการทำงานของระบบ CRM Tracking และการอัปเดตสถานะแบบเรียลไทม์ แนะนำให้ทดสอบตามขั้นตอนนี้:

### ขั้นที่ 1: การสร้างลิงก์พ่วง QR Code การตลาด
1. สลับหน้าจอเป็น **Marketing Admin**
2. เลือก Campaign "ฉลองเปิดร้านใหม่ ครัวพระคุณ" และเลือก Source "คอนโด PST อาคาร A (โบรชัวร์)"
3. คลิกปุ่ม **"สร้างลิงก์สำหรับแคมเปญการตลาด"**
4. ระบบจะแสดงผลลัพธ์ URL ที่ฝังพารามิเตอร์พร้อมรูปภาพ QR Code
5. คลิกปุ่ม **"จำลองการสแกน QR Code นี้"** (ระบบจะนำคุณสลับไปหน้าลูกค้าพร้อมบันทึกพารามิเตอร์ที่มา)

### ขั้นที่ 2: ลูกค้าเลือกอาหารและทำรายการสั่งซื้อ
1. ใน **หน้าลูกค้า** สังเกตป้ายกำกับแคมเปญด้านบนขวาจะแสดงตัวเลือกการตลาดที่เราเพิ่งเปิดเข้ามา
2. คลิกเลือกเมนู **"ข้าวผัดกะเพราหมูกรอบ"**
3. ปรับตัวเลือกความเผ็ด ท็อปปิ้ง และพิมพ์สั่งความต้องการเพิ่มเติม แล้วคลิก **"ใส่ตะกร้า"**
4. คลิกแถบตะกร้าอาหารลอยด้านล่างเพื่อสไลด์หน้าต่างสรุปรายการ
5. คลิก **"LINE Login"** (หรือเบอร์โทรศัพท์) เพื่อจำลองการเชื่อมโยงระบบสมาชิก
6. กรอกที่อยู่จัดส่งและข้อความถึงไรเดอร์
7. สแกน QR Code จำลอง และลากไฟล์ภาพสลิปชำระเงินใดๆ มาปล่อยใส่ช่องอัพโหลด
8. ยืนยันยอมรับ Consent แล้วคลิก **"ยืนยันรายการสั่งซื้ออาหาร"**
9. หน้าจอจะเปลี่ยนเข้าสู่หน้า **Order Status Tracking (Stepper)** เพื่อรอตรวจสอบ

### ขั้นที่ 3: เจ้าของร้านตรวจเช็กสลิปหลังบ้าน
1. สลับบทบาทหน้าจอไปเป็น **Store Admin**
2. ในแถบ **"จัดการออเดอร์"** คุณจะเห็นออเดอร์ใหม่สถานะ "รอตรวจสอบสลิป" เพิ่มเข้ามา
3. คลิกแถวออเดอร์เพื่อดูรายละเอียด ตรวจรูปภาพสลิปการโอน และข้อมูลผู้สั่งซื้อพร้อมช่องทางการตลาด
4. คลิกปุ่ม **"ยืนยันยอดเงินโอน (Verify)"** เพื่ออนุมัติ

### ขั้นที่ 4: พนักงานครัวรับช่วงและปรุงอาหาร
1. สลับบทบาทหน้าจอไปเป็น **ห้องครัว**
2. ออเดอร์ที่ Admin กดยืนยันเงินเมื่อครู่จะเด้งไปอยู่ในคอลัมน์ **"ยืนยัน/รับแล้ว"** ในทันที
3. คลิกปุ่ม **"เริ่มปรุงอาหาร"** (การ์ดจะขยับไปคอลัมน์ "กำลังปรุงอาหาร")
4. คลิก **"ปรุงสำเร็จ (พร้อมส่ง)"** (การ์ดจะขยับไปคอลัมน์ "กำลังส่ง / พร้อม")
5. สลับบทบาทกลับไป **หน้าลูกค้า** สังเกตว่าหน้าจอติดตามสถานะจะขยับตามการทำครัวของพนักงานไปเรื่อยๆ

### ขั้นที่ 5: ตรวจรายงาน CRM และ ROI แคมเปญ
1. ในหน้า **Store Admin** คลิกแถบ **"ฐานลูกค้า & CRM"** เพื่อสังเกต Preferences รสนิยมความชอบของลูกค้าท่านเมื่อกี้
2. คลิกปุ่ม **"ดูประวัติ"** เพื่อดู Timeline ประวัติการสั่งซื้อ และ Parameter Attribution
3. สลับหน้าจอไปเป็น **Marketing Admin** เพื่อสังเกตสถิติยอดการสั่งซื้อสะสมและ ROI ของโบรชัวร์คอนโดที่จะอัปเดตแบบเรียลไทม์
